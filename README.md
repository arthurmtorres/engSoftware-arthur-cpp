# Projeto C++ - Práticas de Gitflow e TDD

Este repositório foi criado para aplicar os conceitos de versionamento de código ensinados nos tutoriais do TerraLAB, utilizando metodologias ágeis.

## Estrutura do Projeto

- `src/`: Códigos-fonte (.cpp, .hpp)
- `include/`: Cabeçalhos adicionais (se necessário)
- `bin/`: Executáveis e binários gerados pela compilação
- `test/`: Arquivos de testes unitários/regressivos
- `doc/`: Documentação

## Como Compilar e Executar

Para compilar a aplicação principal:
`make` ou `make all`

Para compilar os testes:
`make test`
